# @l-fight/dataset

Общий ассет-датасет: каталоги картинок + промпты (`src/generated/`), S3-ключи фонов/локаций.

Геймдата Lightborn — в `@l-fight/lightborn-dataset`.

```ts
import { listBackgrounds, backgroundObjectKey, type AssetImage } from "@l-fight/dataset";
```

Каталоги: `monster-images`, `npc-images`, `item-icons`, `skill-icons`, `avatar-images`, `location-images`, `backgrounds`, `game-icons-rename-map`.
